# Security Policy

## Scope

This policy covers:

- The Weave website at [workoutstories.app](https://workoutstories.app) (this repository)
- The Weave iOS app

## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

Report them privately through one of these channels:

1. **Private Vulnerability Reporting** (preferred) — open a report on the
   [Security Advisories](https://github.com/hoelzlm/weave-site/security/advisories/new) page.
2. **Email** — send details to [info@rinnebuehl.de](mailto:info@rinnebuehl.de) with
   "SECURITY" in the subject line.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- The affected page, or the app version and iOS version
- A suggested fix, if you have one

## What to Expect

- Acknowledgement of your report within 3 business days
- An initial assessment within 14 days
- Updates while the issue is being fixed
- Credit in the fix announcement, unless you prefer to stay anonymous

Please give us a reasonable amount of time to fix the issue before disclosing it publicly.

## Supported Versions

Only the latest version is supported: the currently deployed website and the
latest Weave release on the App Store.
